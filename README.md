# Tempo — мобільний застосунок (вайбкодинг)

Перший екран: Splash (Figma node 2804:27852).

Запуск на localhost (потрібен Node.js 18+):

    npm install
    npm run dev

Відкриється http://localhost:4310 — зміни в index.html оновлюються одразу (hot reload).

- `index.html` — екран (стилі й токени кольорів на початку файлу)
- `assets/` — ассети з Figma (PNG 2–4x, чіткі на Retina)
- `design-reference-*.png` — макети для порівняння
